# Отпуск

Одностраничный планировщик отпуска в Германии на любой год (переключатель лет под заголовком).

```sh
task dev     # http://localhost:5273, открывает браузер
task start   # то же на production-сборке
task test    # проверки праздников и подсчёта дней
```

- Клик по рабочему дню — отпуск; протянуть мышкой — несколько дней; Shift + клик — диапазон.
- Выходные и праздники внутри отпуска не списываются (§ 3 BUrlG) и автоматически входят в «поездку».
- Праздники считаются сами для всех 16 земель — по месту работы. Праздники земли, где живёшь, но не работаешь, обведены пунктиром.
- Школьные каникулы земли, где живёшь, загружаются с [openholidaysapi.org](https://openholidaysapi.org) и кэшируются в браузере.
- Земли работы и дома — настройка каждого года: переезд указывается с того года, где он случился.
- Остаток с прошлого года сгорает 31 марта (§ 7 Abs. 3 BUrlG) — планировщик предупреждает.
- 24.12 и 31.12 по закону рабочие; как их считает фирма (целый день, ½ или выходной) — настройка.

Планы по годам хранятся в localStorage браузера; новый год берёт настройки из предыдущего (без остатка). Чтобы перенести их на другое устройство (все годы разом): «Скопировать код плана» → вставить код там → «Загрузить план из кода».

Каждый пуш в `main` собирает сайт и выкладывает его на GitHub Pages (`.github/workflows/pages.yml`).
